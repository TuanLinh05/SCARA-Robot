# Kết quả Webots

`runs/<timestamp>/`: dữ liệu thực nghiệm khi chạy Webots, mỗi lần một thư mục.
`validation/`: báo cáo kiểm tra offline. `webots_physics_tested: false` có nghĩa
chưa chạy vật lý Webots; không dùng báo cáo này để kết luận lực/sai số thực tế.

Xem `webots/README.md` để giải thích cột CSV và cách đọc bằng MATLAB.
